# AGENTS.md — Presentation Domain

## Routing

**description:** Prompts for building branded HTML presentations and matching Google Apps Script artifacts for Google Slides import

**use_when:** User wants to build a slide-ready HTML presentation, convert content to Google Slides, or generate a `.gs` script from a content brief

**not_when:** User wants a document, proposal, solution brief, or non-slide deliverable — use `sales-architecture` or `product-delivery` instead
